웨딩 청첩장 웹사이트 사용 안내

1. 압축을 푼 뒤 index.html 파일을 브라우저에서 열어 확인하세요.
2. index.html / style.css / script.js는 각각 HTML / 디자인(CSS) / 동작(JavaScript) 파일입니다.
3. images 폴더의 사진은 첨부해 주신 시안 이미지에서 잘라 넣은 실제 이미지 파일입니다.
4. 예식 날짜, 이름, 예식장 주소, 계좌번호, 은행명은 예시이므로 실제 정보로 수정하세요.
5. 지도 버튼은 Google Maps에서 'Grand Wedding Hall Seoul Gangnam'을 검색하도록 연결되어 있습니다.
6. 계좌번호 복사 기능은 브라우저 보안 정책상 로컬 파일 환경에서 제한될 수 있습니다. 이 경우 안내 팝업에 번호가 표시됩니다.
